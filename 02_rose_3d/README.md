# Nine Pink Roses — Soft Hologram

九朵粉玫瑰收拢成一束，花茎在底部自然并拢。没有包装，没有丝带、蝴蝶结或外盒。绿色叶片全部通过叶柄连接在实际花茎上，没有悬浮、散开的叶片。

## 规格

- 单位：米，Y 轴向上，原点位于花茎底部中心附近（茎束最低点约 `0.018 m`）。
- 9 朵粉玫瑰，9 根独立花茎，12 片独立叶片，30 个可单独选择/渲染的节点。
- 315,036 三角面，干净流形拓扑；叶片与花茎独立，花瓣、花萼、叶柄、叶脉分别命名。
- 叶柄从花茎上的实际连接点延伸至叶片，所有叶片都不是漂浮对象。
- 没有牛皮纸、没有粉色丝带、没有蝴蝶结、没有外包装。
- 材质为柔和粉色的半透明感 PBR；页面叠加了淡淡的冷白轮廓光，适合白底全息旋转。

## 打开预览

打开：

**http://127.0.0.1:4173/rose-pastel/**

页面控制：

- `PAUSE MOTION` 暂停/继续旋转；
- `CUBE` 显示/隐藏浅色线框立方体；
- `GLB` 下载完整模型；
- URL 参数：`?still=1` 固定姿态，`?clean=1` 隐藏界面，`?cube=1` 直接显示立方体，`?a=-7` 指定初始角度。

## 结构说明

- `ROSES`：9 个独立花头节点，每个花头包含 41 片独立花瓣、花心与花萼。
- `STEMS`：9 根独立花茎，弯曲后在腰线处自然并拢。
- `FOLIAGE`：12 片独立叶片；每个叶片有从花茎连接点延伸出的叶柄，以及较浅的中央叶脉。
- 无包裹层、丝带或外盒节点。

模型以白底展示为目的；叶柄、花茎与花头的真实空间关系已保留，直接放入白色线框立方体即可做全息旋转。
