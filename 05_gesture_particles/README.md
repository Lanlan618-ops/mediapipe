# Holo / Gesture — Four Forms

把 `mediapipe1.0` 的四组视觉资产合并成同一个实时手势粒子体验：

**红玫瑰 → 男人拿花 → 黄色油菜花 → 后背拥抱 → 循环**

全息立方体只有在**左手抬起并张开手掌**时才出现，落在左掌上方并跟随左手移动；**右手**专门控制粒子状态：张开时影像爆散成高密度、明亮的粒子云，握拳时粒子重新聚合成完整模型，并在握拳瞬间切换到下一个形态。

只有 **1 个 Three.js 场景**、**1 个 MediaPipe Hand Landmarker 实例（同时追踪双手）**、**1 个全屏镜像摄像头背景**。原始四个 demo 目录没有改动。

## 打开

在 `mediapipe1.0/` 中启动本地服务器：

```bash
python3 -m http.server 4180
```

打开 <http://127.0.0.1:4180/05_gesture_particles/>。

也可以直接双击上一级的 `start.command`，再从总览页进入。摄像头 API 需要 `localhost` 或 HTTPS，请不要直接双击 `index.html`。

## 手势

| 手势 | 效果 |
| --- | --- |
| 左手抬起并张开 | 全息立方体淡入，落在左掌上方并跟随左手移动；左手落下或握拳时淡出 |
| 右手张开 | 3D 花模型 / 人像影像淡出，高密度粒子明亮爆发；无烟雾、无柔和光团 |
| 右手握拳 | 粒子重新聚合成完整模型；**握拳完成的瞬间**切换到下一个形态 |

不再使用响指，也没有额外冷却。每完成一次「右手张开 → 握拳」只前进一个形态；再次切换必须先重新张开右手。握拳判定带两帧确认和滞回阈值，避免手指临界抖动连续切模。

粒子聚合/消散跟随右手开合连续响应；消散时粒子带逐粒延迟、径向速度与低幅湍流，整体平滑收放；聚合时使用短过渡把上一形态的粒子目标混合到新形态。

## 画面

- 摄像头画面铺满整个视口并做水平镜像，不显示摄像头小窗。
- 全息立方体仅在左手张开时淡入，由左掌托起并随左手平移；左手落下、合拢或离开画面时淡出。
- 外层立方体沿同一方向持续旋转；玫瑰与油菜花使用原始 GLB 3D 模型，并跟随立方体一起旋转。男人拿花与后背拥抱保持正面影像，不随立方体旋转。
- 两朵花下方只保留英文艺术字：玫瑰为 “The Boundary of Letting Go”，油菜花为 “Where Souls Agree”。使用大字号 Instrument Serif Italic 与金线装饰；文字同样随右手张开爆散、握拳重组。
- 立方体增加分段线框、边中节点、内层斜置线框与上下扫描光面，强化科技感；四个模型共用同一套同向连续旋转，转速已提高。
- 视觉由 3D 花模型（花类）/ 半透明人像影像（人像）+ 加色粒子 + 边缘辉光叠加而成，不使用烟雾或额外光团。
- 粒子层是透明背景的 WebGL canvas，`pointer-events: none`。
- 使用 `AdditiveBlending` 发光粒子；根据摄像头画面平均亮度自动调节粒子透明度，深色背景更亮、浅色背景更收。
- 默认叠加右手的青白色科技骨架：发光骨骼线、关节/指尖节点、腕部旋转扫描环；手离开后柔和淡出。
- 顶部只保留当前形态编号、名称和一行半透明手势提示。
- 右手骨架默认显示；打开 `?debug=1` 后切换为双手调试骨架与实时诊断数据。

调试地址：

<http://127.0.0.1:4180/05_gesture_particles/?debug=1>

## 粒子系统

1. 对四张目标图采样不透明像素，得到四组候选点。
2. 取四组中的最大数量作为统一粒子数；当前四张素材生成 **38,559 颗/形态**。
3. 数量不足的形态从自身候选点中重复采样并加入亚像素抖动，四组形态一一对应、可互相插值。
4. 每个目标点保存位置、颜色、尺寸、抖动种子和径向爆发方向。
5. 稳定状态下，花类显示原 3D 模型，人像显示正面影像，少量粒子在表面闪烁；右手张开时模型/影像淡出，完整粒子云在立方体附近形成高亮、密集的爆发。
6. 右手握拳时，粒子目标平滑混合到新形态并收拢；对应的 3D 花或正面人像同步淡入，并切换到下一形态。
7. 顶点着色器同时保存 A/B/C/D 四个形态坐标；切换时按 `from/to` 权重混合，并叠加由粒子种子驱动的随机扩散与湍流。

## 英文字艺术标题

- 玫瑰下方为 **The Boundary of Letting Go**，油菜花下方为 **Where Souls Agree**；不再显示中文题字。
- 使用大字号 **Instrument Serif Italic** + 金线/菱形端点，保持海报式英文标题的细长字形。
- 标题由发光字面层 + 同字形粒子层组成：静止时字形完整，粒子做微光；右手张开时字面消隐、文字粒子爆散；握拳时重新聚合并恢复。
- 文字固定在立方体下部、保持正面朝向；花朵和立方体持续同向旋转，但英文标题始终可读。
- 金线、字形渐变和点光都使用与主体一致的加色材质。

## 技术栈

- Three.js r161（本地）
- GLTFLoader + RoomEnvironment（本地 addons，加载原 GLB 花模型）
- MediaPipe Tasks Vision Hand Landmarker（本地 WASM/模型，双手追踪）
- 无构建步骤；页面与资源全部在本地，不上传画面。

## 文件

- `index.html` / `style.css` / `app.js`：体验页面与全部逻辑
- `assets/targets/`：四张透明目标图（粒子采样 + 人像显示）
- `assets/models/`：玫瑰与油菜花原 GLB 模型
- `assets/vendor/three.module.js`、`assets/vendor/addons/`：Three.js 与 GLTFLoader / RoomEnvironment
- `assets/mediapipe/`：Hand Landmarker、WASM 运行时与本地模型
